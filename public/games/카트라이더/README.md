# 카트라이더 · 오벌 드리프트

첨부 TypeScript 게임을 정적 배포 형식으로 변환했습니다.

모바일은 자동으로 가속하며 좌우 조향·브레이크·드리프트를 동시에 누를 수 있습니다. 브레이크(PC ↓/S)를 누르면 감속 후 후진하고, 놓으면 자동 가속으로 돌아옵니다. 손을 떼거나 앱을 벗어나면 입력이 해제됩니다.
앱 바로가기 버튼은 홈 화면 추가 안내 또는 브라우저 설치를 제공합니다.

수정 가능한 소스: `source/src/`. 이미지 설정: `source/src/assets/manifest.ts`, 이미지 폴더: `assets/`. 경로는 `./assets/파일명`으로 지정합니다.

다시 빌드: `cd source && npm ci && npm run build`. 빌드 결과 `runtime/`도 커밋합니다. 배포 서버에는 Node가 필요 없습니다.
